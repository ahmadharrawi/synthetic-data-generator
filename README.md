# 🧬 Synthetic Data Generator

A lightweight, production-ready web application that uses the Google Gemini 3.8 Flash model to generate highly customized, tabular mock datasets for machine learning testing, prototyping, and data engineering pipelines. 

This tool solves the "cold start" data problem by allowing developers to instantly generate synthetic data that perfectly matches their required schema, distribution, and edge cases without relying on static CSV files or public datasets.

## 🚀 Features
* **Zero Data Dependency:** Generates realistic datasets entirely from natural language prompts, bypassing the need to scrape, clean, or store external data.
* **Instant Export:** Automatically parses the LLM output into a pandas DataFrame and provides a one-click CSV download.
* **Interactive UI:** Built with Streamlit for a fast, responsive, and intuitive user experience.

## 🛠️ Tech Stack
* **Python 3**
* **Streamlit** (Web Framework)
* **Pandas** (Data Orchestration)
* **Google Generative AI** (Gemini 3.8 Flash Engine)
